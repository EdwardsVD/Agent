# Reverse Engineering & Codebase Analysis Superpower

Rapidly inspect, understand, map, and document unfamiliar or legacy codebases.

## Methodology

1. **Top-Level Discovery**:
   - Locate entry points (`main.py`, `index.js`, `manage.py`, `Cargo.toml`, etc.).
   - Map directory layout and identify modules/packages.
2. **Dependency & Flow Mapping**:
   - Trace imports and call chains across files.
   - Generate Mermaid flowchart diagrams representing data flow and system components.
3. **Data Flow & State Analysis**:
   - Trace data structures from input/request handling to storage/output.
4. **Comprehensive Documentation**:
   - Produce high-level architecture overviews, API documentation, and configuration breakdowns.
