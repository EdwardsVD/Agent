# Frontend UI Builder Superpower

Build responsive, accessible, aesthetically pleasing, and lightning-fast web interfaces.

## Standards

1. **Mobile-First & Fully Responsive**:
   - Flexbox & CSS Grid layouts.
   - Designed to render cleanly on phone screens (320px+) as well as desktop displays (1920px+).
2. **Modern Styling**:
   - Modern Tailwind CSS utility classes or cleanly scoped CSS variables.
   - Dark mode support (`class="dark"` / `@media (prefers-color-scheme: dark)`).
   - Glassmorphism, smooth gradients, subtle box shadows, and polished typography.
3. **Accessibility (a11y)**:
   - Proper semantic HTML elements (`<header>`, `<main>`, `<nav>`, `<article>`, `<button>`).
   - `aria-label` attributes for icon-only buttons.
   - High color contrast ratio (> 4.5:1).
4. **Interactive Polish**:
   - Hover states, active focus rings, transition animations (`transition-all duration-200`).
   - Loading skeletons and clean error toasts.
